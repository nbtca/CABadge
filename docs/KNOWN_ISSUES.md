# v1.1.0 已知限制与待验证

- 无 TE：软件 DMA 完成不等于屏幕扫描同步，实屏撕裂/残影仍需目视。
- 当前包完成一次基本检查；真实手指滑动、BLE 对端连接、长时间无线并发及异常断电恢复未全量验收。
- 旧 v1.0 到本版的扩大壁纸分区迁移代码存在，本轮未重测该升级路径；保留图片原文件/设备备份。
- 手机管理按现有产品行为使用开放热点、无访问码，仅在可信近距离环境开启。
- BlueMap 依赖现有远端服务器；网络不可用不等同于本地 renderer 失败。
- 构建仍依赖 Windows/F 盘路径；无 OTA、BLE 传图功能承诺。
- 第三方游戏素材的独立授权范围待核实，见 THIRD_PARTY.md。

历史失败与版本证据保留在首板测试记录.md；不能据新版本基本检查宣称所有旧问题已关闭。
