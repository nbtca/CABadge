# 当前源码已知限制与待验证（7.9.23）

- 无 TE：软件 DMA 完成不等于屏幕扫描同步，实屏撕裂/残影仍需目视。
- 7.9.23 已有烧录哈希与启动版本确认，最新双三击、六主题保存、摇晃飞散及方向切换仍待实屏复测；旧版失败反馈保留。TimeTiles 完全断电后需重新联网或手动校时，运行计时在重启后恢复为暂停。
- BLE 心率已有真实设备 Notify 短测试；异常重连和连接内 30 秒无有效通知的实物复测仍待完成。FluidBox 五模式已有短测试，真实运动跟随、温升及长时间运行仍待验收。
- 真实手指滑动、长时间无线并发及异常断电恢复未全量验收，分项状态见 [HANDOFF](../firmware-v7/HANDOFF.md)。
- 旧 v1.0 到本版的扩大壁纸分区迁移代码存在，本轮未重测该升级路径；保留图片原文件/设备备份。
- 手机管理按现有产品行为使用开放热点、无访问码，仅在可信近距离环境开启。
- BlueMap 依赖现有远端服务器；网络不可用不等同于本地 renderer 失败。
- 构建流程仍面向 Windows，工具目录可通过 `CABADGE_BUILD_ROOT` 配置；无 OTA、BLE 传图功能承诺。
- 第三方游戏素材的独立授权范围待核实，见 THIRD_PARTY.md。

历史失败与版本证据保留在首板测试记录.md；不能据新版本基本检查宣称所有旧问题已关闭。
