# 已知限制

- 屏幕的 TE 信号线未接，DMA 完成只说明数据已送出。实屏撕裂、残影和触摸观感需要目视确认。
- TimeTiles 完全断电后需联网或手动校时，运行计时在重启后恢复为暂停。
- 从旧 v1.0 升级涉及壁纸分区迁移。升级前请保留原图和设备备份。
- 手机管理使用无访问码的开放热点，适合在可信近距离环境开启。
- BlueMap 依赖远端地图服务器。
- 当前版本支持通过 USB 或局域网 HTTP 传图。OTA 和 BLE 传图尚未提供。
- 第三方游戏素材的授权范围见[第三方来源](THIRD_PARTY.md)。

实测方法、结果及历史失败见[首板测试记录](../首板测试记录.md)。待测清单见[实板复测跟踪](https://github.com/nbtca/CABadge/issues/10)。
