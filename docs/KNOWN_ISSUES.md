# v1.0 已知问题与待验证项目

当前固件 7.3.7-mem 已按用户反馈基本可用，但仍存在较多 Bug，后续持续修复。用户尚未在本轮提供逐项问题及复现步骤，不虚构具体故障。

|事项|当前状态|后续验收|
|---|---|---|
|日常使用问题|用户确认仍有较多 Bug，明细待补充|记录触发步骤、现象、固件版本，修复后逐项复测|
|动态显示|TE 未接；旧版故障保留在主测试记录|以 7.3.7 实屏目视及复现材料为准|
|无线、上传与持久化异常场景|本轮没有完整回归证据|补充连接、并发、断连与失败恢复验证|
|长期运行与触摸边界|本轮没有量化覆盖证据|记录测试条件、时长与实际结果|
|构建可迁移性|保留既有 Windows/F 盘路径，未验证干净环境重建|按构建说明恢复环境后独立验证|
|公开发布准备|仓库私有；项目整体许可证未确定|核对个人信息、素材及第三方许可后再公开|

历史失败不自动视作当前版本仍复现；基本可用反馈也不自动关闭所有历史待测项。主记录以根目录《首板测试记录.md》为准。
