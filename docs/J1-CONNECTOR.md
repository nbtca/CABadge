# J1 屏幕连接器采购更正

## 首板实际换装规格

用户在说明首板换座后可正常显示的上下文中，提供了所用连接器的商品选项截图。选中项为：

**FFC/FPC 0.5mm-18P-抽屉上接（5只）**。

- 间距：0.5 mm；针数：18P。
- 锁扣形式：抽屉式；接触形式：上接触。
- “5只”是商品包装数量；每块板 J1 用量为 1 只。
- 不要选截图列表中的“18P 翻盖下接”。

截图没有提供厂家、准确 MPN、立创料号或尺寸图，因此这些字段未补造。本文记录截图可确认的采购规格，不认定任意同名商品均与本板封装兼容。购买时仍需核对焊盘、固定脚、接触方向、排线厚度及安装空间。

## 与原设计记录的关系

原 BOM / 采购表登记为 `FPC-05F-18PH20 / C2856802`。现已从当前采购字段移除，不能继续把它当成换座后已验证的料号。BOM 的 J1 Value 原来写的是屏幕型号，现在改为连接器规格；屏幕本体型号仍为 `W180TE010I-18Z(CTP-A1)`。

已打板 PCB、原理图、封装库、交互式 BOM 和 v1.0 冻结生产文件保留原设计快照。其中出现的旧 J1 型号/封装标识不代表当前采购推荐。BOM Footprint 列保留原 PCB 封装名，仅用于追溯，不能当作新连接器 MPN。

## 验证与版本

“换座后正常显示”来自既有用户实板反馈；本次截图补充采购规格，没有提供厂家图纸、尺寸测量或新增电气测试。

当前主分支的 BOM 与采购表已更正。v1.0 标签下的旧源码包仍含原 J1 条目，复刻时请结合本更正及主分支采购表；冻结硬件、固件二进制和发布附件不重写。
