# BOM 与两版 PCB 用料差异

> **版本范围：** 本目录 CSV、料号列表及对比数据保留 2026-10-20 的 V1 / V2.1 KiCad 用量记录，交互式 BOM 为 V1 快照。本次仅集中存放并修正链接，未继续核对或修改料号与数量；V2.1 的当前 EDA 已替换为 2026-10-27 原生重画版，器件核对已停止，参见[当前版本说明](../pcb/current/README.md)。

更新日期：2026-10-20。对比旧首板 **c7c59dff** 与 **V2.1 KiCad / 9d094d57** 的实际 PCB 元件；原理图、PCB 和冻结生产包保持原样。V2.1 新增电源与机构仍待实板验收，本次完成的是清单核对。

## 下载与选择版本

- [逐位号 BOM](BOM-DRAFT.csv)：保留器件型号、料号、封装、DNP，新增“版本归属、旧版用量、新版用量、差异说明”。以“位号＋型号”区分版本，因此 **SW1 有两行，分别对应旧拨动开关和新轻触按键**。
- [按采购型号合并的清单](LCSC_IMPORT_LIST.csv)：同时列出两版位号和数量；原“位号、数量”列默认表示**新版 V2.1**。“旧版数量”用于复刻旧首板。数量均为每板净用量，不含采购备损。
- [V2.1 已知立创料号列表](LCSC_IMPORT_NEW_CODES.txt)：只包含新版数量大于 0 且料号已知的去重代码。文件名中的 `NEW` 沿用历史命名，**不表示这些料号全部为新版独有**；数量以采购 CSV 为准。U7、J1 和电池没有已核实的代码，不在 TXT 中。
- [结构化对比记录](pcb-version-comparison.json)：两版源文件 SHA-256、计数、换型与位置变化。
- [交互式 BOM](ibom.html)：仍是旧首板快照，下载后在浏览器打开；**不能作为 V2.1 的完整清单**。

在 CSV 中筛选目标版本的“用量／数量 > 0”再采购。两版共用器件也需按对应版本的数量准备，不要把两列相加。BOM 保留 `DRAFT` 文件名；J1、U7 料号等未确认项仍需按下文核实。

## 新增、旧版独有与换型

|位号／器件|版本归属|旧版每板|新版每板|说明|
|---|---|---:|---:|---|
|U7，GEK100_13，SOT-23-6|新版 PCB 独有|0|1|新增按键电源控制器，指定 **1 秒开／3 秒关**的 `_13` 后缀；立创料号未核实|
|C32，100 nF／50 V／X7R，0603|新版 PCB 独有位号|0|1|沿用已有 `CC0603KRX7R9BB104 / C14663`，不是新增采购型号|
|SW1，JS102011SAQN / C221660|旧版 PCB 独有型号|1|0|旧拨动开关；新版不要购买此型号|
|SW1，HX-2X4X3.5CA-2.5N / C49234137|新版 PCB 独有用法|0|1|新版改为轻触电源键；同型号在旧版 SW2、SW3 已有使用|
|R40，10 kΩ / C25804|两版共用|1|1|仅从 (105.4, 122.9) mm 移到 (111.3, 115.8) mm 避让外壳，型号和用量不变|
|其余原有器件|两版共用|见 CSV|见 CSV|未发现其他器件换型；网络用途变化不等于新增采购型号|

**没有删除的旧版位号。** 新版净增 U7、C32 两个位号，并保留 SW1 位号进行换型。“旧版独有”指 JS102011SAQN 这个器件型号，不代表 SW1 位号从新版消失。

按采购型号合并后，数量变化为：

|采购型号|立创编号|旧版每板|新版每板|对应位号|
|---|---|---:|---:|---|
|GEK100_13|未核实|0|1|新增 U7|
|CC0603KRX7R9BB104|C14663|13|14|原 13 只加 C32|
|HX-2X4X3.5CA-2.5N|C49234137|2|3|SW2、SW3 加新版 SW1|
|JS102011SAQN|C221660|1|0|仅旧版 SW1|

U7 原 PCB 的 MPN／立创字段为空，BOM 按板上 `GEK100_13` 值和[广昇官方数据手册](https://gsctek.com/uploads/allimg/20251225/1-251225110HM63.pdf)补充型号、封装和时间后缀，不代填立创编号。C32 与新版 SW1 的采购型号依据其与现用 C5、SW2／SW3 **完全相同的项目封装及既有采购记录**关联，没有改动 CAD 字段。

## 两版共同的装配约定

|项目|两版当前装配用量|处理方式|
|---|---:|---|
|C12、C13|各 0|RF 调谐预留，PCB 中为 DNP，无确定采购值|
|J3 电池座|0|用户装配约定：电池正负两线直焊；PCB 焊盘仍保留。原型号仅用于追溯|
|BAT_EXT|1|450 mAh、42×30×4 mm 电池，是整机外购件，不是 PCB 新位号；厂家型号、保护板参数及公差未提供|
|J1|1|沿用首板换装的 FFC/FPC 0.5 mm、18P、抽屉式上接触规格；现用厂家型号、料号与尺寸图未提供，不把 CAD 旧 `C2856802` 当作已验证采购型号|

J1 与电池装配依据见 [J1 更正说明](../../docs/J1-CONNECTOR.md)及[电池与屏幕连接器](../pcb/archive/V1_c7c59dff/README.md#电池与屏幕连接器)。J1 保留旧封装名称用于追溯，实际采购仍需核对接触方向、焊盘尺寸和排线定义。

按上述 DNP 与 J3 装配约定统计，旧版为 **94 个 PCB 实装器件＋1 只外购电池**，新版为 **96 个 PCB 实装器件＋1 只外购电池**。PCB 文件中分别有 108／110 个封装，其中 3 个 FID 和 8 个测试点不作为采购件；剩余 97／99 个器件位号包含上述 3 个不装位号。屏幕、线材、外壳和紧固材料不计入这两个 PCB 实装数量，仍需按整机装配资料准备。

## 清理的历史冲突与对比依据

采购表中重复的 D2、L3“候选”行已与现用行合并，避免重复采购。两版实际 PCB 都已使用 DSK34、DFE201610E-R47M=P2 及表内现用的 0603 阻容；“0402 待改”“保留 0805”的旧候选说明不适用于这些行，已按真实 PCB 更新，**不将这些历史变更误标为 V2.1 新增**。D2 品牌按 [C727076 的立创产品记录](https://www.lcsc.com/product-detail/C727076.html)更正为 TWGMC；L3 按 [C269773 的立创产品记录](https://www.lcsc.com/pl/product-detail/C269773.html)更正为 Murata。没有更换器件选型。
