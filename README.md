# CABadge · 计协电子吧唧

CABadge 是为计算机协会设计的可自定义电子徽章。项目希望将传统吧唧的身份表达与电子屏幕的可变内容结合，让佩戴者通过壁纸、图案和协会名片展示个人喜好与社团归属。

它以日常佩戴和内容展示为核心：平时展示喜欢的画面，需要时通过触摸操作切换内容，通过无线连接或电脑工具更新壁纸、管理设备。界面尽量简洁，让展示内容本身成为主角。

本仓库记录 CABadge 从硬件设计、固件开发到配套工具和实板测试的过程，为后续问题修复、功能完善及协作开发提供统一基础。

## 当前进展

首个发布版本为 **v1.0**，对应固件 **7.3.7-mem**。用户已确认该固件上板使用，基本功能可正常使用，但仍存在较多 Bug，后续将持续修复和完善。

v1.0 是项目的首个可用基线，不代表所有功能、异常场景和长期稳定性均已完成验证。具体状态见 [发布说明](docs/RELEASE-v1.0.md) 和 [首板测试记录](首板测试记录.md)。

## 硬件与功能

- ESP32-S3、16 MB Flash、8 MB Octal PSRAM；360×360 圆形 ST77916 显示屏与触摸。
- LVGL 界面：壁纸展示与选择、协会名片、连接管理、基础设置和可选 FPS 显示。
- Wi-Fi、BLE 双角色服务；USB 和本地 HTTP 静态壁纸上传与存储。
- SC7A20 摇晃唤醒；Windows 原生 NBTCA Badge TOOL 工作台。
- 固定硬件基线：`JXBadge_EVT_20260909_c7c59dff`。实体显示使用 40 MHz QSPI；TE 未连接，不承诺所有场景无撕裂。

以上为实现范围，不等于各功能在当前版本均已完整回归。GIF、BLE 传图和 OTA 不作为本次发布能力。

## 下载与使用

从 [v1.0 Release](https://github.com/Egger0/CABadge/releases/tag/v1.0) 下载烧录包，按包内说明操作；固件内部版本仍为 `7.3.7-mem`。源码包不包含历史二进制、虚拟环境和编译缓存。

[安装与构建说明](docs/BUILD.md) 包含固件解压位置、烧录地址、Windows 工具依赖及现有构建限制。工作台入口为 `firmware-v7/run.cmd`；使用其离线预览还需要本地构建桌面程序。
