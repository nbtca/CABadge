# CABadge · 计协电子吧唧

CABadge 是为计算机协会设计的可自定义电子徽章。项目希望将传统吧唧的身份表达与电子屏幕的可变内容结合，让佩戴者通过壁纸、图案和协会名片展示个人喜好与社团归属。

它以日常佩戴和内容展示为核心：平时展示喜欢的画面，需要时通过触摸操作切换内容，通过无线连接或电脑工具更新壁纸、管理设备。界面尽量简洁，让展示内容本身成为主角。

这里收录硬件设计、固件源码、配套电脑工具和实板测试记录，供复刻、改进和协作开发使用。

**当前正式版本：v1.1.0 / 内部固件 7.9.2-memory。** 包含统一缓存位图转场、Direct Compositor 和内存优化。已完成编译、烧录及基本功能检查；长期稳定性与完整人工验收仍在完善。

[下载 v1.1.0](https://github.com/nbtca/CABadge/releases/tag/v1.1.0) · [发布与升级说明](docs/RELEASE-v1.1.0.md) · [已知问题](docs/KNOWN_ISSUES.md) · [实板测试记录](首板测试记录.md)

## 可以做什么

- **展示与切换壁纸**：圆形触摸屏展示静态图片，支持浏览、选择和保存上传的壁纸。
- **展示协会名片**：内置计协风格名片页面。
- **连接与管理设备**：Wi-Fi、BLE 连接管理，通过 USB 或本地 HTTP 上传壁纸。
- **基础交互**：触摸操作、亮度设置、息屏后摇晃唤醒，以及可选 FPS 显示。
- **电脑端调试**：Windows 原生 NBTCA Badge TOOL 提供固件安装与设备联调入口。

## 硬件概览

|部分|当前方案|
|---|---|
|主控|ESP32-S3R8，8 MB Octal PSRAM|
|外部 Flash|W25Q128JVSIQ，16 MB|
|显示与输入|360×360 圆形 ST77916 屏幕、触摸输入|
|运动传感器|SC7A20|
|主电源|SGM62117 升降压至 3.3 V|
|充电|TP4056-MS，配合外围供电分配与充电使能电路|
|PCB|直径 50 mm、四层板、名义板厚 1.6 mm|

当前配套硬件为 **JXBadge_EVT_20260909_c7c59dff**。完整器件型号、封装及采购编号见 [BOM](hardware/BOM-DRAFT.csv)。

## 如何开始复刻

复刻需要自行采购、焊接和调试。板上包含 QFN 主控和细间距 FPC 连接器，建议具备贴片焊接与万用表排查经验，并准备放大观察工具及合适的焊接设备。

**流程：下载配套资料 → 核对采购 → PCB 打样 → 分阶段焊接与上电 → 烧录 → 功能检查。** 已有装配完成的同版硬件，可以从第 5 步开始。

### 1. 下载固件与配套硬件

**最新固件请下载 [v1.1.0](https://github.com/nbtca/CABadge/releases/tag/v1.1.0)**，升级方法见[当前发布说明](docs/RELEASE-v1.1.0.md)。下面 v1.0 附件表保留为硬件制造包与历史基线索引，不是最新固件。

打开 [v1.0 Release](https://github.com/Egger0/CABadge/releases/tag/v1.0)，按用途下载：

|文件|用途|
|---|---|
|`CABadge-v1.0-hardware-c7c59dff.zip`|PCB 生产包、可选钢网文件与下单说明|
|`CABadge-v1.0-firmware-7.3.7-mem.zip`|已发布的烧录文件、安装说明与校验值|
|`Source code (zip)`|查看原理图、BOM、固件源码和项目文档|
|`CABadge-v1.0-debug-7.3.7-mem.zip`|ELF 与构建配置，仅排查问题时需要|

首次点亮直接使用发布固件，无需先搭建编译环境。下载后可通过 Release 的 `SHA256SUMS.txt` 核对附件完整性。

### 2. 核对器件与装配

先查看 [BOM](hardware/BOM-DRAFT.csv)、[采购料号表](hardware/LCSC_IMPORT_LIST.csv) 和 [交互式 BOM](hardware/bom/ibom.html)。交互式 BOM 下载到本地后用浏览器打开，可对照板上位置检查元件。

需要看电路时，用 KiCad 10 打开 [JXBadge_V1.kicad_pro](hardware/JXBadge_V1.kicad_pro)，保留同目录的原理图、符号库、封装库及 3D 模型。

采购时重点核对屏幕完整型号、排线引脚定义、FPC 座的接触方向与封装，不能仅凭“360×360”或“18 针”判断兼容。电池也需核对极性、保护、尺寸与安装空间。BOM 文件保留 `DRAFT` 名称，采购前应结合原理图和 [首板测试记录](首板测试记录.md) 复核，不能当作已验证的即买即装套件清单。

### 3. PCB 打样

解开硬件附件，将其中的 **`JXBadge_EVT_20260909_c7c59dff_PCB.zip`** 交给板厂；不要上传外层发布压缩包，也不要把钢网包当作 PCB 包。

按 [下单说明](hardware/fabrication/JXBadge_EVT_20260909_c7c59dff/下单说明.md) 核对四层、1.6 mm 板厚、50 mm 圆板及目标叠层 `JLC04161H-7628`。叠层、孔工艺和局部间距要求需由板厂确认。需要钢网时，另外使用 `TOP_STENCIL.zip`。

### 4. 分阶段焊接与首次上电

按 [焊接与分阶段上电检查](焊接与分阶段上电检查_首板.md) 分组完成：USB 输入 → 3.3 V 电源 → 主控与 USB 下载 → 屏幕与触摸 → 电池与充电。

首次排查可以只用 USB 供电、不接电池。每增加一组先断电检查焊接与短路，再上电测量；不要带电插拔屏幕排线。确认主电源和主控正常后再接入屏幕。

首板换装的 J1 规格为 **FFC/FPC 0.5 mm、18P、抽屉式上接触**，换座后已成功显示。当前 [BOM](hardware/BOM-DRAFT.csv) 与 [采购表](hardware/LCSC_IMPORT_LIST.csv) 已按截图更正；厂家型号和尺寸图仍未提供，采购前须核对封装与接触方向。**v1.0 旧源码、原理图和交互式 BOM 中仍有原 J1 条目，采购请以 [J1 连接器更正](docs/J1-CONNECTOR.md) 为准。**

### 5. 烧录 7.3.7-mem

解压固件包，按包内 `INSTALL.md` 或 [安装与构建说明](docs/BUILD.md) 操作。烧录前核对校验值和硬件版本，使用支持数据传输的 USB 线，并释放被其他程序占用的串口。

|文件|烧录地址|
|---|---|
|`bootloader.bin`|`0x0`|
|`partitions.bin`|`0x8000`|
|`firmware.bin`|`0x10000`|

可以用 esptool 直接烧录，也可以使用 v7 工作台的固件安装入口。使用工作台时，将固件解压到源码根目录下的 `outputs/cabadge-v7-mem-20260921/`；具体 Python 依赖见安装说明。

烧录完成后 RESET，确认启动的固件版本为 **7.3.7-mem**。不要为了普通升级额外执行全片擦除，以免清掉已有设置和壁纸。

### 6. 检查自己的板子

依次检查开机显示、触摸与翻页、壁纸切换、Wi-Fi/BLE 基本连接，再检查上传壁纸及重启后的保留情况。遇到问题时记录固件版本、触发步骤和现象，附上照片或串口日志，方便复现与修复。

当前固件保留背光上限和充电使能限制，不能把“成功开机”当作电池充电、满亮度或长期运行都已验证。显示 TE 未连接，动态画面仍需观察是否撕裂；具体待办见 [已知问题](docs/KNOWN_ISSUES.md)。

## 继续开发

完成首次点亮后，再按 [安装与构建说明](docs/BUILD.md) 恢复开发环境。当前工程使用 LVGL 9.4.0；桌面预览基于 SDL2，板端使用 ESP-IDF / PlatformIO。构建脚本仍有 Windows 和 F 盘路径限制，尚未整理成跨平台的一键构建流程。

|目录|内容|
|---|---|
|`firmware-v7/`|当前固件、UI、工作台、协议与测试|
|`hardware/`|KiCad 工程、项目库、BOM 与生产文件|
|`tools/flasher/`|共用烧录工具|
|`docs/`|安装、构建、发布与已知问题说明|

历史实验固件、原始日志和本地备份没有全部随仓库上传，旧文档中的部分研究链接仅保留为历史出处。`v1.0` 标签固定首次发布快照，后续改进从主分支继续。
